# Colorist Eye プライバシーポリシー

更新日：2026年9月30日

Colorist Eye は LinkLiu が開発・提供しています。このポリシーでは、アプリの利用時およびサポートへのお問い合わせ時における情報の取り扱いを説明します。

## 1. アプリ内のデータ処理

Colorist Eye にアカウント登録は不要です。現在、第三者の広告、利用状況分析、アプリをまたぐトラッキングは組み込んでいません。

写真処理、練習画像の生成、スコープの計算は端末内で行います。読み込んだ写真、練習記録、設定を開発者のサーバーへ自動送信することはなく、開発者がアプリを通じて遠隔から読み取ることもできません。

## 2. 写真と練習用コピー

写真を読み込むときは、システムの写真選択画面で自分で選びます。アプリが取得するのは選択した画像だけで、ライブラリ全体を自動で調べることはありません。

アプリは後の練習に使うため、処理した練習用コピーをアプリ内の保存領域に保管します。読み込みや練習によって写真ライブラリ内の元画像は変更されません。

アプリ内のライブラリで「コピーを削除」を選ぶと、該当する練習画像を削除できます。写真ライブラリ内の元画像は削除されません。

## 3. 練習記録と設定

アプリは練習記録、デイリーチャレンジの結果、効果音の設定などを端末内に保存し、結果の表示や設定の保持に使用します。

これらの情報をアプリが開発者に自動送信することはなく、広告やアプリをまたぐトラッキングにも使用しません。

## 4. データの保持・削除・バックアップ

読み込んだ練習用コピーは、該当するコピーを削除するか、アプリとそのローカルデータを削除するまでアプリ内に残ります。

アプリを削除すると端末内のローカルデータも削除されますが、システムの「Appを取り除く」機能では書類とデータが残る場合があります。

端末の設定により、アプリのデータが iCloud またはコンピュータのバックアップに含まれる場合があります。バックアップは Apple のシステムと選択した方法で管理され、開発者はアクセスできません。ローカルデータを削除しても、既存のバックアップ内の該当データが直ちに消えるとは限りません。バックアップはシステム設定で管理できます。

## 5. サポートメール

あなたがサポートメールを送る場合、開発者はメールアドレス、本文、任意で添付したファイルを受け取ります。これらはフィードバックへの対応、問題の調査、返信のためにのみ使用します。

パスワード、認証コード、不要な機密情報は送らないでください。サポートメールは問題への対応、必要なフォローアップ、適用法令への対応に必要な期間のみ保持し、広告には使用しません。法令上の保存義務がある場合を除き、下記のメールアドレスから削除を依頼できます。

メール事業者は自社の利用規約とプライバシーポリシーに従って送受信と保存を処理します。

## 6. サポートサイトと外部サービス

このプライバシーポリシーとサポートページは GitHub Pages で公開しています。ウェブページへのアクセス時、ホスティングサービスが IP アドレスなど必要なアクセスログを処理する場合があります。詳しくは [GitHub のプライバシーに関する声明](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement) をご覧ください。

ウェブサイトへのアクセスは、アプリ内での写真処理とは別のものです。サポートページを開いても、練習写真や練習記録がサイトへアップロードされることはありません。

## 7. ポリシーの更新

アプリの機能やデータ処理方法が変わった場合は、このポリシーと上記の更新日を改訂します。別途通知や同意が必要な変更は、適用される要件に従って対応します。
